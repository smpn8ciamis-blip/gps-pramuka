# GPS Pramuka Android

Aplikasi native Android untuk GPS Tracker Pramuka SMPN 8 Ciamis.

## Fitur
- Foreground Service (GPS kirim 24/7)
- Input kode regu
- Tombol SOS
- Auto-start HP reboot

## Build APK
- Push ke GitHub → Actions auto-build
- Download APK dari tab Actions → Artifacts

## Server
- Kompatibel dengan server v12: `pramuka.smpn8ciamis.sch.id`
